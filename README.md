# Dutch Seasons | 荷蘭節慶行事曆

Bilingual Traditional Chinese / English, calendar-first Netherlands festival prototype.

## Deployment

Upload `index.html` to the root of the GitHub repository. Vercel can deploy this as a static site without a build command. The website's current festival data is embedded in `index.html`; `festivals-data.json` is an accompanying export for future development.

## Data caveat

This is a static snapshot of approved festival entries, not a live Google Sheets connection. Dates marked as 2026 historical or estimated seasonal windows must not be interpreted as confirmed 2027 dates.
